# Singapore Maritime Energy Analytics

Interactive portfolio project analyzing Singapore's maritime-energy hub role, bunker fuel transition, and Iran/Hormuz supply-chain risk transmission.

## Highlights

- Built a 1995-2025 Singapore port and energy analytics story.
- Compared the 2025 Twelve-Day War with the 2026 Hormuz crisis.
- Found that direct Iran oil-import exposure was near zero after 2019, while indirect Gulf exposure remained material.
- Created an ECharts interactive data-story page.
